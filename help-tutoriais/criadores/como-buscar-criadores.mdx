## Dúvidas frequentes

<AccordionGroup>
  <Accordion title="A busca não encontra o criador" icon="search">
    Confira a grafia do nome e tente de novo. Se a lista continuar vazia, use os filtros para ver quem está disponível para a marca.

    {/* TODO: confirmar se a busca inclui criadores sem relação com a marca e o que a tela mostra quando não há resultado. */}

  <Accordion title="Quando usar os filtros em vez do nome" icon="list-filter">
    Use os filtros quando você não sabe o nome exato, ou quando a lista está grande demais para ler nome por nome. O nome é o caminho mais curto quando você já sabe quem procura.
