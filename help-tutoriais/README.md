# Central de Ajuda Conty (prévia)

Protótipo Mintlify, em português, de um tutorial do painel da marca. A configuração parte do [Mintlify starter](https://github.com/mintlify/starter) (`docs.json`), com a cor primária `#1A73E8` e a fonte Inter.

## Pré-visualizar

Na pasta `help-tutoriais`:

```bash
npx mint dev
```

O tutorial escrito fica em `/criadores/como-buscar-criadores`. As outras páginas só reservam a navegação.

As animações em `images/tutoriais/` são simulações geradas por `scripts/gerar-gifs-mock.py`. Não são capturas do produto.
